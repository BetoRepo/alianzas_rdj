# Imagenes del Proyecto

Coloca las imagenes en esta carpeta con los siguientes nombres:

## Login (Split-Screen)
- `scout-login.jpg` — Foto panoramica de scouts en naturaleza (bosque/camping)
  - Recomendado: 1200x800px minimo, formato JPG/WebP
  - Se muestra en el panel izquierdo del login (solo desktop)

## Dashboard del Scout
- `scout-banner.jpg` — Foto sutil de tropa para el banner de bienvenida
  - Recomendado: 1200x400px, formato JPG/WebP
  - Se muestra con opacidad 20% como fondo del banner

## Logo (Opcional)
- `logo.png` — Logo de Alianzas RDJ
  - Recomendado: 200x200px, fondo transparente (PNG)
  - Reemplaza la "S" dorada en el sidebar

## Ilustraciones de Estados Vacios (Opcional)
- `empty-courses.svg` — Ilustracion para "No hay cursos disponibles"
- `module-completed.svg` — Ilustracion para "Modulo completado"
